2. Run one Double Pass sequence

KEEP THE COMPARISON CLEAN

Observe first. Explain later.

Use the same device and primary input for both Double Pass versions. Start each from a fresh run, do not reveal the solution in advance, and record what the player actually did before discussing preferences.

Useful questions: Did real time add anticipation or mainly pressure? Did stepping clarify cause and effect or feel tedious? Which failures felt attributable to a decision rather than presentation or input latency?

Keep both records paired: In Other observations for each version, write the same anonymous pair label (for example, Pair 01) and the order used: Sequence A (timed first) or Sequence B (step first). This preserves the play order without collecting names.

If you choose to paste observations into the public GitHub issue, leave out names, contact details, and other identifying information. Sharing is optional.
